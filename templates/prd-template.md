# PRD 模板

用户没有提供自己的模板或样稿时，使用本 PRD 模板。它是可裁剪的参考，不是必填目录：

- 用户提供了模板、样稿或已有成稿时，以用户格式为准，不用本 PRD 模板覆盖。
- 表格只保留适用内容；空表和逐项“不涉及”不进入正文。
- 简单的规则调整可以只保留“背景与目标、功能需求、验收标准”三部分。
- 标注“按需”的章节，只在需求确实涉及时输出。
