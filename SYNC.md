# Method sync

This repository is a vendor-neutral Agent Skill. An internal suite may add repository preparation, private APIs, or knowledge search. Only portable methodology is synced into this repository.

## Direction

- Stable, vendor-neutral rules move from the internal suite into this repository.
- This repository keeps a flat layout: `SKILL.md`, `references/`, `templates/`, and `examples/`.
- Internal sub-skills, platform clients, business knowledge bases, and organization-specific PRD templates are not mirrored here.

## In scope

- Readiness intake; requirement assessment; statement layering; clarification versus open questions.
- Full-read gate for designated materials; prototype evidence boundaries.
- Multi-option confrontation before a build conclusion.
- Code access levels L0–L4; hop-by-hop verification discipline; evidence credibility labels.
- Synthetic regression cases without real project identifiers.

## Out of scope

- Organization-specific default chapter trees or department template names.
- Internal git hosts, API keys, environment files, or clone automation for private platforms.
- Business knowledge dumps, real product traces, or production identifiers.
- Tooling that runs only inside a private workspace.

## Pull request checklist

Search the diff for organization or product names, internal hostnames, credential material, private skill directory names, and real repository paths. Rewrite or remove matches.

The default PRD template in this repository includes acceptance criteria and code clues unless the user opts out. Internal defaults that omit those sections are not the public default.
